ULA sound paths
===============

ULA port writes carry two separate audio signals: D3 (MIC, active low in the
port value) and D4 (EAR/beeper).  They used to be encoded into a two-bit index
at the ULA write site and passed to sound_beeper().  That function selected a
single amplitude table and sent it to the same left/right Blip_Buffer objects
as AY and peripheral audio.  It also suppressed MIC-only output except while
playing a tape with loading sound enabled.

sound_ula() now retains the raw logical ULA states until sound_ula_update().
The tape EAR input remains a separate input; it is combined with D3 only at the
ULA output node, as in the former implementation.  Tape edge events call
sound_tape() to render that node at their exact emulated tstate.  This keeps
ROM tape load/save semantics separate from the D3 logical state.  In
particular, tape saving continues to use the ULA's raw D3 state, while an
ordinary D3-only port write is not made audible by the speaker path.  This
preserves the distinction relevant to Fuse bug #501 rather than treating
MIC-only as general speaker audio.

There is one mono ULA Blip buffer and synth. At each ULA update it renders
only the selected logical path; changing Speaker type clears its old Blip
history and starts the newly selected path from the current ULA state. This
avoids both PCM work and allocation for an inactive ULA path.

The MIC path represents the ULA output node and has the following steady levels
for the ULA bits (D4:D3):

  00  0
  01  SOUND_AMPL_TAPE
  10  SOUND_AMPL_BEEPER
  11  SOUND_AMPL_BEEPER + SOUND_AMPL_TAPE

Thus the electrical MIC-only state is retained.  The beeper buffer represents
the drive to the internal speaker and, without tape playback loading sound,
has these levels:

  00  0
  01  0
  10  SOUND_AMPL_BEEPER
  11  SOUND_AMPL_BEEPER + SOUND_AMPL_TAPE

MIC-only is suppressed here by explicit threshold policy, not by discarding
D3.  D3 still adds SOUND_AMPL_TAPE when D4 is high, so 10 and 11 remain
distinct. SOUND_AMPL_BEEPER is 50 * 256 and SOUND_AMPL_TAPE is 2 * 256,
retaining the 50:2 relationship.  The existing optional tape loading sound
is retained only while a tape is playing (and is disabled for Timex).  When
loading sound is disabled, the old policy of suppressing the MIC
contribution during playback is also retained.

The main left/right buffers contain SpecDrum, Covox and sources which bypass
the selected speaker response. A separate left/right TV bus receives built-in
AY and SP0256 when TV output is selected. The selected mono ULA path retains
its own buffer: its electrical response is applied first, then it is added
equally to the TV bus before the shared speaker response. External AY
interfaces remain in the main mix because their analogue output connection is
interface-specific. The machine AY capability distinguishes built-in from
external AY.

Only the currently selected ULA logical path is submitted to its Blip synth;
the inactive path does no PCM or filter work. In Beeper and Unfiltered modes
the selected ULA signal is mixed identically into both final channels. In TV
mode it joins each TV channel before filtering. The rendered source-local ULA
PCM remains available through sound_ula_mic_output() and
sound_ula_beeper_output(), with their corresponding count accessors, until the
next sound_frame().

The Speaker type setting selects the final ULA contribution:

  Automatic   Beeper for machines with the libspectrum beeper capability;
              TV speaker otherwise. Enabling Currah uSpeech selects TV output
              because the original interface feeds speech and the Spectrum
              MIC lead into the television signal.
  TV speaker  (MIC path -> electrical pole) + built-in AY + uSpeech
              -> shared TV speaker response
  Beeper      internal-speaker path -> electrical pole -> built-in speaker
              model; AY, uSpeech and other sources remain in the main mix
  Unfiltered  MIC path -> 16 Hz DC blocker; AY and other sources remain
              unchanged in the main mix

The three explicit output types are universal ULA-output overrides, not master
EQ over unrelated peripherals. Covox, SpecDrum and external AY always bypass
the speaker response and remain in the main mix. Automatic follows the
physical output provided by the emulated machine, except that a connected
Currah establishes a TV path on a built-in-beeper machine too.

The ULA Blip buffer has no built-in DC cancellation. In Unfiltered mode only,
the selected ULA MIC path passes through a first-order 16 Hz DC blocker. Its
recurrence is `y = a * ( y + x - x_previous )`, where
`a = exp( -2*pi*16/Fs )` at the runtime sample rate. The first target
establishes its steady input level without a route-selection transient. State
persists across frame boundaries and resets on sound initialization,
sample-rate reconfiguration and selection of the Unfiltered route. AY and the
other sources in the main mix bypass this blocker. The TV and Beeper paths use
the DC rejection already provided by their respective response models.

The electrical pole is the frozen asymmetric first-order candidate from a
listening experiment which had respondants comparing recordings of real
machines to candidate filters. It is an effective ULA electrical/MIC-output
approximation, not a claim that the physical ULA circuit is one pole and not a
model of the internal speaker. It operates on the generated post-Blip PCM, so
Blip ringing deliberately participates in the choice of rise or fall
coefficient. Its one state belongs to the selected ULA path. A new sound
generator or speaker-type selection initializes it from the first PCM target;
state never resets at a frame boundary. An explicit machine reset atomically
clears the rendered ULA buffer and reader state, resets the pole, and makes the
current logical ULA level the Blip synth's silent baseline. This prevents the
first post-reset sound frame and ULA write from observing different old state,
and avoids manufacturing an artificial transition at reset.

The frozen time constants are 36.53558495933805 us rising and
68.86073172982108 us falling. At the real output sample rate Fs their
coefficients are `-expm1( -1 / ( Fs * tau ) )`. For each input target x and
persistent output y, the rise coefficient is used exactly when `x > y`; the
fall coefficient is used otherwise, then `y += alpha * ( x - y )`. There is no
additional gain, offset, clipping, resonator, or frequency-dependent tuning.
It is applied before the ULA enters either final mixing or the TV bus. It never
colours AY, SpecDrum, Covox or SP0256; built-in AY and SP0256 receive only the
later shared TV response when routed to that bus.

The built-in speaker model is a single second-order resonant high-pass.
Research on original 16/48K speakers is incomplete and production variation is
likely. The available evidence describes a very small moving-coil transducer
with a plastic/Mylar-like diaphragm. Issue 1/2 machines used nominally 200-ohm
units and Issue 3-6 nominally 40-ohm units, but their physical speakers appear
broadly similar. Comparable miniature Mylar speakers with roughly 10-13 mm
moving systems have a dominant mechanical resonance in the several-hundred-Hz
to approximately 1 kHz range. This supports modelling that low-frequency
transition, rather than a conventional narrow band-pass speaker.

  H(s) = s^2 / (s^2 + (w0 / Q)s + w0^2)

It uses a conventional RBJ/bilinear digital biquad at the runtime host sample
rate. The nominal experimental parameters, defined in sound/speaker_filter.c,
are f0 = 750 Hz and Q = 1/sqrt(2). The filter is applied only in the Beeper
case, immediately before final PCM mixing; it never changes raw ULA PCM. Its
state is reset on audio/AY reset and when switching between filtered and
unfiltered routes. After reset, its first target establishes the steady level
without creating a route-selection transient. This is a deliberately minimal
acoustic model: it adds no high-frequency low-pass, EQ peaks, enclosure
response or distortion.

The TV speaker response is a first-order 100 Hz high-pass followed by a
first-order 10 kHz low-pass. Both use matched exponential coefficients at the
runtime sample rate. The high-pass recurrence is
`h = a * (h + x - x_previous)`, where `a = exp(-2*pi*100/Fs)`. The low-pass is
`y += b * (h - y)`, where `b = -expm1(-2*pi*10000/Fs)`. It uses the same
first-target initialization policy as the built-in speaker. State persists
across frame boundaries and resets on sound initialization,
sample-rate reconfiguration and route changes.

The response follows the analogue sum, not each source independently. Stereo
output therefore has independent left and right filter state: separated
built-in AY channels retain their placement, while mono ULA and uSpeech feed
both channels. The main mix and filtered bus are combined and clipped once at
final PCM output. Switching routes rebinds eligible synths; old TV filter state
is never inherited by a newly selected stream.
